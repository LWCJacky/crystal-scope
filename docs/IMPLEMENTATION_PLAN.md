## 2. 架構：四層責任分離

```
src/
├─ core/            幾何計算（純 TypeScript，不得 import Vue / Three）
│  ├─ types.ts        Vec3、CellParams、BasisAtom、Structure…
│  ├─ lattice.ts      晶胞參數驗證、基底矩陣、分率 ⇄ 直角座標
│  ├─ periodic.ts     座標折返 [0,1)、週期複本與邊界複本生成
│  ├─ direction.ts    晶向 [uvw] 驗證、方向向量、最簡整數比
│  ├─ centering.ts    心型 P／C／I／F 的平移向量與晶格點類型
│  └─ constraints.ts  各晶系典型晶胞設定的幾何鎖定
├─ data/            科學資料
│  └─ crystalSystems.ts  七大晶系：名稱（中/英）、典型晶胞、說明、晶胞設定
├─ render/          3D 渲染（Three.js，不得 import Vue）
│  └─ CrystalRenderer.ts  場景、相機、實例化球體、晶胞邊線、座標軸、晶向箭頭
├─ stores/          Pinia 狀態
│  └─ structure.ts    結構、選取、週期設定、晶向、歷史紀錄（復原／重做）
└─ components/      Vue 介面
   ├─ AppHeader.vue       名稱、探索／投影模式、重置、說明
   ├─ SystemList.vue      七大晶系選單（左）
   ├─ ViewportCanvas.vue  掛載 CrystalRenderer（中）
   ├─ ControlPanel.vue    晶胞參數、原子位置、晶向、顯示設定（右）
   └─ AnimationBar.vue    播放／暫停／速度／進度（底）
```

**規則**

1. `core/` 為唯一的幾何真實來源；元件與渲染層只呼叫它，不自行換算座標。
2. 基底原子有穩定 `id`；視覺複本 = `{ baseId, offset: [i,j,k], isBoundaryImage }`，永不寫回儲存。
3. 渲染層採「按需重繪」：只有相機、資料或動畫變動時才 render；切換模型時 `dispose()` 幾何與材質。
4. 球體以 `InstancedMesh` 繪製；晶胞邊線用 `LineSegments`，視覺上與化學鍵區分（細、半透明、不畫成圓柱）。

## 3. 核心數學約定

- 基底矩陣（a 沿 x 軸、b 在 xy 平面）：
  - a⃗ = (a, 0, 0)
  - b⃗ = (b cosγ, b sinγ, 0)
  - c⃗ = (c cosβ, c (cosα − cosβ cosγ)/sinγ, c·√(1 − cos²α − cos²β − cos²γ + 2cosα cosβ cosγ)/sinγ)
- 位置：r = x·a⃗ + y·b⃗ + z·c⃗；複本：r = (x+i)·a⃗ + (y+j)·b⃗ + (z+k)·c⃗
- 反換算：以基底矩陣反矩陣求分率座標（非正交晶胞不可直接用螢幕 XYZ）。
- 有效晶胞：長度 > 0、各角 ∈ (0°, 180°)、體積因子平方 > ε（排除共面／退化）。
- 週期折返：`wrap(x) = x − ⌊x⌋`，並將 1−ε 以上與 −0 正規化為 0；拖曳中不折返，放開後才正規化。
- 邊界複本：座標≈0 的原子在 N 位置額外顯示淡色複本，標記 `isBoundaryImage`，不計入原子數、不可刪除。
- 晶向：d⃗ = u·a⃗ + v·b⃗ + w·c⃗；禁止 [000]；第一版為三指數，整數輸入，顯示最簡整數比。

### M0 專案骨架（本次完成）

- [x] Vite + Vue 3 + TS + Three.js + Pinia + Vitest
- [x] `core/` 幾何模組與單元測試（座標往返、非正交基底、退化晶胞、週期邊界、晶向）
- [x] 七大晶系資料（三方以「菱面體軸 hR 設定」示例並明示）
- [x] 三區版面殼層＋可旋轉 3D 檢視（顯示晶胞、原子、週期複製）
- [x] `BASE_PATH` 子路徑建置設定
- [x] 14 種布拉菲晶格選擇；原子／晶格點視圖切換；依晶格點類型著色（角落／底心／體心／面心）與圖例、每晶胞晶格點數

### M1 最小垂直功能（依規劃書第 12 節）

一個晶胞 → 顯示原子 → 編輯分率位置 → 週期複製同步 → 重置

1. 右側「原子位置」面板：選取原子，數值輸入／滑桿編輯 x、y、z，分數吸附切換（0、1/4、1/2、3/4）。
2. 3D 點選原子 → 高亮＋顯示 id、元素、分率座標（Raycaster 對 InstancedMesh 取 instanceId → 對應 baseId）。
3. 週期同步：修改基底原子 → 所有複本即時更新。
4. 復原／重做（快照堆疊）、還原範例。
5. 編輯後標示「自訂結構（來源：xxx）」。
6. 驗收：在三斜晶胞中編輯後，畫面位置與 `fracToCart` 一致（測試＋手動）。

### M2 七大晶系與晶胞參數

1. 晶胞參數面板：a、b、c、α、β、γ；教學模式套用 `constraints.ts` 鎖定，自由模式解除並改標「自訂」。
2. 無效輸入即時提示且不套用。
3. 修改晶胞時保持分率座標不變（原子隨晶胞變形）。
4. 週期 Na/Nb/Nc 1–5、快捷 1×1×1／2×2×2／3×3×3。
5. 顯示開關：晶胞邊線、座標軸、標籤、原子／晶格點視圖切換。
6. 視角：預設、沿 a/b/c 觀看、一鍵重置。

### M3 晶向 [uvw] 模組

1. u、v、w 整數輸入，拒絕 [000]；快捷 [100]、[010]、[001]、[110]、[111]。
2. 箭頭：起點可平移（分率座標）、顯示長度獨立可調；方向不隨起點改變。
3. 沿所選晶向觀看。
4. 與原子編輯完全分離：修改晶向不移動原子。

### M4 3D 拖曳與動畫

1. 原子 3D 控制柄：沿 a/b/c 約束移動（以晶格基底換算），拖曳中停用 OrbitControls。
2. 新增／刪除原子、元素選擇（刪除僅作用於基底原子）。
3. 建立動畫：座標軸 → 晶胞邊線 → 晶格點 → 展開週期排列；播放／暫停／重播／調速。
4. 尊重 `prefers-reduced-motion`：直接顯示終態。

### M5 投影模式、響應式與開源交付

1. 投影模式：隱藏次要設定，放大名稱與數值。
2. 窄螢幕：控制面板改為抽屜／分頁。
3. README（截圖、操作、限制）、LICENSE（建議 MIT，待擁有者定案）、CONTRIBUTING、科學資料來源說明。
4. GitHub Pages 建置驗證（子路徑資源載入）。※ 建立遠端、推送、部署需使用者另行指示。

### 後續（第二、三階段，非第一版）

BCC/FCC/HCP 的真實材料範例（HCP 為晶體結構非晶格）、雙模型比較、JSON 匯入匯出、晶面米勒指數、六方四指數 [uvtw]、配位環境、超晶胞與缺陷、堆疊動畫。
